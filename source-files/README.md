# Source files

Raw, full-resolution exports kept for reference. **Nothing in this folder is
served by the website** — the site only uses optimized copies in
`public/assets/`.

| Folder | Contents |
|---|---|
| `rendezvous-cafe-new/` | Signature series N° 01–04, Christmas reel, All-Day Favorites film, festive Beef Curry ad (Nov 2026 batch) |
| `solarworks-new/` | *More Than Solar Panels* and *The Bill* vertical reels, v1 (Nov 2026) |
| `solarworks-new-v2/` | Tagalog versions of both reels — the versions now on the site |
| `videos-to-add/` | Earlier batch of video masters (Rendezvous, SolarWorks, Fifth Ave Dogs) |
| `portfolio-archive/` | Older portfolio material, Figma app exports, and archived social templates |
| `loose-exports/` | Individual image/video exports that used to sit in the repo root |

When adding new work: drop the raw files here, then copy a web-ready version
into `public/assets/social/<brand>/` (kebab-case filenames) and register it in
`src/data/social.ts`.
